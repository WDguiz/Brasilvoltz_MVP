# Contribuindo com o BrazilVoltz

Obrigado pelo interesse em contribuir com o projeto.

O BrazilVoltz é uma iniciativa Open Source voltada para o gerenciamento inteligente de carregamento de veículos elétricos. Toda contribuição da comunidade é bem-vinda.

## Como contribuir

1. Faça um Fork do repositório.
2. Crie uma Branch para sua alteração.
3. Realize as modificações necessárias.
4. Teste suas alterações.
5. Envie um Pull Request para revisão.

## Reportando Problemas

Utilize a aba **Issues** para:

* Relatar bugs;
* Solicitar funcionalidades;
* Sugerir melhorias;
* Informar problemas de documentação.

## Boas Práticas

* Manter o código organizado;
* Utilizar nomes descritivos;
* Documentar alterações relevantes;
* Seguir os padrões definidos pelo projeto;
* Respeitar as diretrizes da comunidade.

## Código de Conduta

Todos os participantes devem manter uma comunicação respeitosa e colaborativa, contribuindo para um ambiente aberto e inclusivo.
